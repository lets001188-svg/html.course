LEARNING GOALS

학습 목표

강의를 마친 뒤 수강생이 스스로 할 수 있게 되는 핵심 역량입니다.

핵심 학습 목표

“HTML 문서의 기본 구조와 자주 쓰는 요소를 이해하고, 간단한 단일 페이지의 구성 원리를 익힙니다.”

01

HTML 기본 뼈대 이해

웹 브라우저가 문서를 읽고 화면에 표시하기 위해 필요한 기본 문서 구조를 정확히 파악합니다.

02

자주 쓰는 핵심 요소 활용

제목, 문단, 링크 등 웹페이지의 내용을 구성하는 필수 태그의 역할과 올바른 쓰임새를 익힙니다.

03

단일 웹페이지 구성 원리 습득

영역을 나누고 기본적인 스타일을 연결하여, 한눈에 읽히는 단일 웹페이지의 전체 흐름을 설계합니다.

CURRICULUM

강의 목차

총 5개 단원으로 구성되어 있으며, 각 단원을 클릭하면 세부 학습 내용을 확인할 수 있습니다.

웹사이트가 화면에 보이는 원리를 이해하고, 웹 문서의 뼈대를 만드는 마크업 언어인 HTML의 역할과 태그(Tag)의 기본 개념을 배웁니다.

웹페이지의 원리 HTML의 역할 태그 기본 개념

모든 HTML 파일이 공통으로 가지는 기본 틀(문서 선언, html, head, body 영역)을 살펴보고, 설정 정보와 실제 화면에 보이는 영역의 차이를 익힙니다.

<!DOCTYPE html> <head>와 <body> 문서 저장과 실행

글의 위계를 나누는 제목 태그, 읽기 좋은 본문을 만드는 문단 태그, 다른 페이지나 페이지 내 특정 위치로 이동시키는 링크 작성법을 실습합니다.

제목 태그 (<h1>~<h3>) 문단 태그 (<p>) 하이퍼링크 (<a>)

내용을 구역별로 묶어 정돈된 화면 구조를 만드는 방법과, 글자 크기·색상·여백 등 기본 스타일을 적용해 가독성을 높이는 원리를 익힙니다.

영역 나누기 색상과 글자 크기 여백과 정렬 기초

1강부터 4강까지 배운 요소를 하나로 모아 간단한 단일 소개 페이지를 완성해 보고, 자주 실수하는 부분을 점검하며 전체 내용을 복습합니다.

수강 안내

처음 코딩을 접하는 성인 학습자도 부담 없이 참여할 수 있도록 안내해 드립니다.

추천 수강 대상

  • HTML과 웹페이지 제작을 처음 배우는 성인 학습자
  • 코딩 경험은 없지만 웹사이트가 만들어지는 원리를 기초부터 알고 싶은 분
  • 간단한 단일 소개 웹페이지를 직접 구성해 보고 싶은 분
  • 기초 용어부터 천천히, 반복 설명이 있는 수업을 선호하는 분

수강 준비 및 진행 안내

  • 수업 형태: 온라인 강의 (PC 또는 노트북 화면을 보며 실습 병행 권장)
  • 준비 사항: 인터넷 연결이 가능한 PC(또는 노트북)와 웹 브라우저
  • 선수 지식: 별도의 사전 코딩 지식이 필요하지 않습니다.
  • 학습 팁: 강의 중 나오는 짧은 예제를 직접 입력해 보면 이해가 훨씬 빠릅니다.
